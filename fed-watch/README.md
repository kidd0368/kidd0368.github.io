# 聯準會政策錯誤雷達｜研究路徑 02

網址：https://kidd0368.github.io/fed-watch/（密碼保護）

研究問題：通膨預期仍穩定時，聯準會轉鷹究竟只是一次預防性升息，還是政策錯誤的起點？

## 頁面怎麼判斷

頁面把兩件事分開：

1. **市場正在交易的政策路徑**：Kalshi、Polymarket、金十快訊轉述的 CME FedWatch，加上透明反應函數與專家言論，產生未來四次 FOMC 的升降息分布。
2. **總經證據最接近哪個情境**：用通膨預期與成長／就業組成四象限，再用信用條件判斷政策錯誤是否只有風險，還是已獲得更完整確認。

四種互斥情境：

- 通膨預期穩定、成長有韌性：一次預防性升息或口頭轉鷹。
- 通膨預期失錨、成長有韌性：重新啟動升息循環。
- 通膨預期穩定、成長轉弱：政策錯誤風險。
- 通膨預期失錨、成長轉弱：停滯性通膨陷阱。

情境門檻位於 `config.json` 的 `scenario_rules`。這些都是待回測的研究門檻，不是 Fed 規則、交易訊號或已核准的投資門檻。

## 資料與模型

- **市場層（原權重 0.5）**：Kalshi、Polymarket，以及金十快訊轉述的 CME FedWatch。
- **模型層（原權重 0.3）**：核心 PCE、核心 CPI 三個月動能、10 年損益兩平通膨率代理、就業、油價、殖利率曲線與實質利率七項訊號。
- **專家層（原權重 0.2）**：21 日觀察窗內的券商與經濟學家言論，以 14 日為時間衰減半衰期；少於 3 條時停用。
- **政策情境層（不併入上述權重）**：另看初領失業金、高收益債利差、芝加哥聯準銀行 NFCI 與銀行放款標準。此層專門找出市場、模型與總經資料的矛盾，不改寫既有升降息機率。

## 持續追蹤

- GitHub Actions 每日 4 次更新（台北 03:23、09:23、15:23、21:23），也可手動觸發。
- 每次更新保存市場機率、模型分數與政策情境；情境歷史採追加方式保留。
- CPI、核心 PCE、非農或 FOMC 後，下一輪會重新分類。單次變化先標示為暫定，等後續市場或官方資料交叉確認。
- 頁面另列出台灣與海外公司的傳導路徑、最先驗證的指標與反證。公司名單只是觀察範圍，不代表已確認受益或受害。

## 加密與限制

- `data/store.enc`、`data/annotations.enc` 與頁面 payload 使用 AES-256-GCM；瀏覽器端輸入密碼後解密，密碼不會送到網站伺服器。
- 這仍是公開 GitHub Pages 網址上的客戶端加密，不是 GitHub 帳號登入。拿到網址與密碼的人可以離線解密，因此不要轉傳。
- 本頁是個人研究工具；市場價格是預期，不是事實；股價反應是重新定價訊號，不足以單獨證明需求、毛利、信用或資本支出已經改變。

## 維護

- 每次 FOMC 結束後，將 `config.json` 的 `meetings` 往前滾動，並更新 `current_target`。
- 工作流程：`collect.py` 收集資料；`model.py` 計算三層機率與四象限特徵；`build_page.py` 產生加密頁面。
- Secrets：`PAGE_PASSWORD`、`FRED_API_KEY`，以及選用的 `JIN10_MCP_TOKEN`。
